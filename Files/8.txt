EXP-8: Write a Pig Script for Log File Analysis

Objective:
Analyze a log file using Apache Pig (example: count requests per IP/status)

----------------------------------------

STEP 1: Create Sample Log File (Local)

nano log.txt

Add sample data:
192.168.1.1 - - [10/Oct/2023] "GET /home" 200
192.168.1.2 - - [10/Oct/2023] "GET /login" 404
192.168.1.1 - - [10/Oct/2023] "POST /form" 200
192.168.1.3 - - [10/Oct/2023] "GET /home" 500
192.168.1.2 - - [10/Oct/2023] "GET /home" 200

----------------------------------------

STEP 2: Load File into HDFS

hdfs dfs -mkdir /user/cloudera/logs
hdfs dfs -put log.txt /user/cloudera/logs/

Verify:
hdfs dfs -ls /user/cloudera/logs

----------------------------------------

STEP 3: Open Pig Shell

pig

----------------------------------------

STEP 4: Pig Script (Log Analysis)

-- Load Data
A = LOAD '/user/cloudera/logs/log.txt' USING PigStorage(' ')
    AS (ip:chararray, dash1:chararray, dash2:chararray, date:chararray,
        request:chararray, status:int);

-- Project Required Fields
B = FOREACH A GENERATE ip, status;

-- Group by IP
C = GROUP B BY ip;

-- Count Requests per IP
D = FOREACH C GENERATE group AS ip, COUNT(B) AS total_requests;

-- Display Output
DUMP D;

----------------------------------------

Expected Output:

192.168.1.1    2
192.168.1.2    2
192.168.1.3    1
