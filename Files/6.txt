EXP-6: Implement Flume script for spooling a directory from local file system to HDFS

STEP 1: Check Hadoop & HDFS
hdfs dfs -ls /

If this works → Hadoop is running  
If not:
start-all.sh

----------------------------------------

STEP 2: Create HDFS Output Directory
hdfs dfs -mkdir -p /user/cloudera/flume/output

Check:
hdfs dfs -ls /user/cloudera/flume

----------------------------------------

STEP 3: Create Local Spool Directory
mkdir -p /home/cloudera/spooldir

Add sample files:
echo "Hello Hadoop" > /home/cloudera/spooldir/file1.txt
echo "Flume Example" > /home/cloudera/spooldir/file2.txt

----------------------------------------

STEP 4: Create Flume Configuration File
nano spool-to-hdfs.conf

Paste the following configuration:

agent1.sources = source1
agent1.channels = channel1
agent1.sinks = sink1

# SOURCE
agent1.sources.source1.type = spooldir
agent1.sources.source1.spoolDir = /home/cloudera/spooldir
agent1.sources.source1.fileHeader = true

# CHANNEL
agent1.channels.channel1.type = memory
agent1.channels.channel1.capacity = 1000
agent1.channels.channel1.transactionCapacity = 100

# SINK
agent1.sinks.sink1.type = hdfs
agent1.sinks.sink1.hdfs.path = hdfs://localhost:8020/user/cloudera/flume/output
agent1.sinks.sink1.hdfs.fileType = DataStream
agent1.sinks.sink1.hdfs.writeFormat = Text

# CONNECT
agent1.sources.source1.channels = channel1
agent1.sinks.sink1.channel = channel1

Save:
Ctrl + X → Y → Enter

----------------------------------------

STEP 5: Run Flume Agent

flume-ng agent \
--conf /etc/flume-ng/conf \
--conf-file spool-to-hdfs.conf \
--name agent1 \
-Dflume.root.logger=INFO,console

----------------------------------------

STEP 6: What Happens Internally

1. Source (SpoolDir)
   - Reads files from /home/cloudera/spooldir
   - Converts each line into Flume Event

2. Channel (Memory)
   - Stores events temporarily

3. Sink (HDFS)
   - Writes events into /user/cloudera/flume/output

----------------------------------------

STEP 7: Verify Output in HDFS

Open new terminal:
hdfs dfs -ls /user/cloudera/flume/output

View data:
hdfs dfs -cat /user/cloudera/flume/output/*

----------------------------------------

Output:
Hello Hadoop
Flume Example
